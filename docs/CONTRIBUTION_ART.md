# Contribution art — preview only

`design/contribution-art-preview.svg` compares 3×5, 4×7 and 5×7 letter grids. The compact 3×5 full name with widened N/M occupies 51 columns, fitting inside the approximately 53-week, seven-row GitHub calendar with one blank row above and below. The two larger full-name fonts exceed the width. Compact N and M are necessarily stylized; preview readability should be approved before creating an art repository.

This pass generates no art commits, no historical dates, no future dates and no new repository. The preview is not embedded in genuine engineering telemetry. Actual GitHub contributions include other projects and cannot be erased or guaranteed to reproduce a pristine grid. Contribution visibility also depends on GitHub attribution rules and account settings.

If approved later: create a dedicated clearly documented public profile-art repository, associate commits with a verified GitHub email, and use dates that have already occurred. Each future cell remains pending until its date arrives. Existing project histories must never be rewritten. Each art commit must be explicitly labeled art rather than engineering output. Use a reviewable dry-run date/cell plan before any historical commit operation. No such executable commit generator is included here.

An existing public dedicated repository, https://github.com/sultankassam/contribution-art, was discovered and inspected after the initial profile research. Its README already distinguishes art from engineering and documents date-safe progression. This pass changes neither its files nor histories. The new preview is an independent typography comparison, not an instruction to replace the existing selected bitmap.
